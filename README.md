# FabledRealms

![Screenshot (12)](https://github.com/Fantasya63/FabledRealms/blob/main/github_page_assets/Screenshot%20(101).png)

A Minecraft clone voxel game for my final project on Computer Programming II

---
# Installation
Clone the repository recursively using
```bash
git clone https://github.com/Fantasya63/FabledRealms.git --recursive
```
Create a visual studio 2022 solution by running
```bash
./vendor/bin/premake/premake5.exe vs2022
```
or by running the GenerateProjects.bat batch file

---
# Opening the project
Double click the FabledRealms.sln to open the sulotion file and press run to run the program.
